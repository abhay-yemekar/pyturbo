## Find an answer quickly

- **My program finishes before I can read the output:** [View output or enable Pause after run](getting-started.md#keep-output-visible).
- **I ran it twice:** [Each new run starts with clear output](running-and-debugging.md#run-and-read-the-result).

## About this edition

This guide describes the current development version. A local or PR preview can
contain changes that have not reached the public site yet; use the matching
branch’s manual when testing a preview. The original [project plan](../project-plan.md)
is a roadmap, not the user manual or a completed-feature checklist.

PyTurbo runs Python in your browser using Pyodide. It borrows the Turbo C++ style
and many key bindings, while running Python rather than C or C++. Enter-only
return from completed output and automatic clearing before a new run are
intentional PyTurbo choices. See [differences and limits](settings-and-troubleshooting.md#differences-and-current-limits).

The manual’s text and screenshots describe PyTurbo. They do not reproduce
Borland’s manual, help text, screenshots, or software. PyTurbo is an independent
project and is not affiliated with Borland or Embarcadero.
